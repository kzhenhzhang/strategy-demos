分析流程

与侧栏「分析流程」一致：先接入数据，再配样本与规则，最后生成并导出。

步骤 1

数据接入

上传 CSV，完成字段识别与列类型初始化。

步骤 2

样本与规则

配置贷前 / 贷后样本、风险比率和规则组合。

步骤 3

生成与导出

生成主报告；下载 HTML 时可勾选 Tab，配置区只读、结果区可筛选。

你能做的三件事

本工具只服务这三件事；术语与界面口径见使用说明。

复盘现有策略

看清「现在这套规则」贷前挡人与贷后风险；用异动归因做自选期深潜（默认跟贷后样本）。

路径：生成分析报告 → 贷前 / 贷后 · 异动归因

挖 / 验新规则

数据分析三区 EDA → 分箱 → 挖规 找规则，有效性里看四象限与 Swap；通过率不够则在残差样本里继续挖。区分 硬规则（命中就拒绝）与 软规则（命中仍可通过，用来观察 / 排序）。

路径：数据分析（①EDA · ②分箱 · ③挖规）→ 规则有效性检查

算单客赚不赚钱 / 风险目标 / 资产包 EL

在假设参数下看单客毛利 / 净利；测算等量换客后的风险目标；或按资产包调配通过率 / 件均 / 金额风险以压组合 EL。三类测算都不需要 CSV。

路径：盈利性测算 · 风险目标测算 · 资产包 EL 调配 Tab
